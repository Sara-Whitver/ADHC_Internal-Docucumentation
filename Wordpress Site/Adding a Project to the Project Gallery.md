# Creating A New Project Post for the Project Gallery

Learn how to efficiently duplicate existing post layouts and enter project details within the WordPress dashboard. This guide provides a step-by-step walkthrough for creating and publishing new archive entries while ensuring proper metadata and citation formatting.
